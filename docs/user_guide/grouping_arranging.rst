Grouping & arranging
====================

fib-o-mat provides some tools to group and arrange :class:`~fibomat.shapes.Shape`\ s, :class:`~fibomat.layout.Pattern`\ s and :class:`~fibomat.layout.Site`\ s. These features are provided by the :mod:`~fibomat.arrangements` submodule.

Grouping
--------

Sometimes it is useful to group :class:`~fibomat.shapes.Shape`\ s, :class:`~fibomat.layout.Pattern`\ s or :class:`~fibomat.layout.Site`\ s together, e.g. to transform them uniformly. Note that a group can only contain elements of the same kind: all elements must either have a unit or not have one. For example, a shape (without a unit) and a pattern (with a unit) cannot be in the same group.

Groups of elements without units (shapes, texts, other groups, ...) are created with the :class:`~fibomat.arrangements.Group` class, groups of elements with units (shapes with a unit, patterns, sites, ...) with the :class:`~fibomat.arrangements.DimGroup` class. Both take the objects to be grouped as parameter.

Grouping of shapes
++++++++++++++++++

As an example, we create a marker consisting of some lines and circles ::

    from fibomat.arrangements import Group

    marker = Group([
        Line((-1, 0), (1, 0)),
        Line((0, -1), (0, 1)),
        Circle(r=.5, center=(0, 0)),
        Circle(r=.05, center=(1 - .05, 1 - 0.05))
    ])

This marker can be added to a pattern like any other shape. All elements of the group share the same patterning settings ::

    site.create_pattern(
        dim_shape=marker * unit('µm'),  # a DimGroup
        mill=Mill(dwell_time=1 * unit('ms'), repeats=1),
        raster_style=raster_styles.one_d.Curve(
            pitch=1 * unit('nm'), scan_sequence=raster_styles.ScanSequence.CONSECUTIVE
        )
    )

The shapes of the group are passed to the backend in the order given in the group.
If the individual elements should have different patterning settings, see the next subsection.

Groups support the same transformations as any other shape. In particular, the :attr:`~fibomat.linalg.Transformable.pivot` property is useful in combination with groups.

Suppose the marker should be added in the four corners of a rectangle, so that the small circle (by default in the upper right corner) is always oriented outwards, but the center of the cross lies on the corner of the rectangle.
All markers can be generated by rotating the original one by 90°, 180° and 270°. By setting the rotation origin to the center of the cross, the center of the cross is invariant under the rotation.
To accomplish this, the pivot of the marker is set to ::

    marker.pivot = lambda self: self.elements[2].center

Here, ``self`` is always a reference to the marker group and ``self.elements[2]`` is the third element in the group, which is the circle with the radius 0.5 and its center at the desired center of the cross.

.. note:: The center of a group is the mean of the centers of its elements. Use the pivot if another point should be used.

Now, we can specify in the rotation call to use the pivot as rotation origin and we get the expected result. ::

    second_marker = marker.transformed(translate((-4, 4)) | rotate(np.pi / 2, origin='pivot'))

Grouping of patterns
++++++++++++++++++++

In the same way as shapes can be grouped, :class:`~fibomat.layout.Pattern`\ s can be grouped with a :class:`~fibomat.arrangements.DimGroup`.

Changing the example from above, we replace the small circle in the upper right corner with a spot. In doing so, we cannot use the same rasterization style for the whole group. The spot needs another rasterization style than the other shapes. Therefore, we create a group containing a pattern for the spot and a pattern for the remaining shapes of the original marker. ::

    from fibomat.arrangements import DimGroup, Group

    center_group = Group([
        Line((-1, 0), (1, 0)),
        Line((0, -1), (0, 1)),
        Circle(r=.5, center=(0, 0))
    ])

    marker_pattern = DimGroup([
        Pattern(
            dim_shape=center_group * unit('µm'),
            mill=Mill(dwell_time=1 * unit('ms'), repeats=1),
            raster_style=raster_styles.one_d.Curve(
                pitch=1 * unit('nm'), scan_sequence=raster_styles.ScanSequence.CONSECUTIVE
            )
        ),
        Pattern(
            dim_shape=Spot((.75, .75)) * unit('µm'),
            mill=Mill(dwell_time=1 * unit('ms'), repeats=1),
            raster_style=raster_styles.zero_d.SingleSpot()
        )
    ])

The marker pattern is added to a site as usual ::

    site += marker_pattern

and can also be rotated and translated, as long as the pivot is set correctly ::

    # we choose again the center of the circle, which is the third element of the first pattern
    marker_pattern.pivot = lambda self: self.elements[0].dim_shape.elements[2].center

    second_marker_pattern = marker_pattern.transformed(
        translate(Vector(-4, 4) * unit('µm')) | rotate(np.pi / 2, origin='pivot')
    )

Note that a dimensioned vector must be passed to the ``translate`` function.

Grouping sites
++++++++++++++

Similar to patterns, :class:`~fibomat.layout.Site`\ s can be collected and manipulated in a :class:`~fibomat.arrangements.DimGroup`. A group of sites is added to a layout with :meth:`~fibomat.layout.Layout.add_site`.


Arranging
---------

fib-o-mat supports the arrangement of objects (:class:`~fibomat.shapes.Shape`\ s, :class:`~fibomat.layout.Pattern`\ s and :class:`~fibomat.layout.Site`\ s, again) in two-dimensional lattices with the :class:`~fibomat.arrangements.Lattice` class (for objects without units) and the :class:`~fibomat.arrangements.DimLattice` class (for objects with units). Any object which is placed in a lattice is moved automatically, so that its pivot is at the lattice point.

These classes are quite flexible. All `2d Bravais lattices <https://en.wikipedia.org/wiki/Bravais_lattice#In_2_dimensions>`__ can be generated. By placing grouped shapes in the lattice, other (non-Bravais) lattices, like the graphene honeycomb lattice, can be generated, too (in this case, the group represents a unit cell containing multiple lattice points).

In general, a two-dimensional lattice is defined by two lattice vectors ``u`` and ``v`` and the objects in the unit cell. The objects are placed at the points ``origin + i_u * u + i_v * v``; ``(i_u, i_v)`` are the indices of the lattice points. A lattice is a group: the elements of a lattice are ordered like the lattice points.

There are three ways to create a lattice. They are class methods of the lattice classes:

.. list-table::
    :header-rows: 1
    :widths: 25 40 35

    * - Method
      - Lattice vectors
      - The size is defined by
    * - :meth:`~fibomat.arrangements.Lattice.from_rect`
      - orthogonal, only the distances of the points (pitches) are given
      - a rectangle: all points which fit in it
    * - :meth:`~fibomat.arrangements.Lattice.from_counts`
      - orthogonal, only the pitches are given
      - the number of points in x and y direction
    * - :meth:`~fibomat.arrangements.Lattice.from_boundary`
      - arbitrary
      - a shape (also with holes): all lattice points inside of it

All methods set the objects at the lattice points in the same way: the argument ``element`` is either a fixed shape (or group of shapes, pattern, ...), which is copied to all lattice points, or a function which creates the element of each point. The function is described below.

For lattices with units, the same methods exist in the :class:`~fibomat.arrangements.DimLattice` class; all lengths are dimensioned values (e.g. ``0.5 * unit('µm')``) and the elements must have a unit.

The indices of the lattice points ``(i_u, i_v)`` start with 0. For the lattices which are created with ``from_rect`` and ``from_counts``, the lattice vector ``u`` points to the right and ``v`` points down. Then, the indices are given by ::

            -- u --> (i_u)

        |   (0, 0) | (1, 0) | (2, 0)
        v   --------+--------+--------
      (i_v) (0, 1) | (1, 1) | (2, 1)
            --------+--------+--------   ...
            (0, 2) | (1, 2) | (2, 2)
            --------+--------+--------
            (0, 3) | (1, 3) | (2, 3)
                        :
                        :

The fast axis
+++++++++++++

The argument ``fast_axis`` defines the order of the lattice points (and, hence, the order of the elements and the order in which the elements are exposed). With ``'x'`` (the default; for lattices which are created from a boundary: ``'u'``), the points are numbered row by row: first all points with ``i_v = 0``, ``i_u = 0, 1, 2, ...``, then ``i_v = 1``, and so on. With ``'y'`` (``'v'``), the points are numbered column by column.

The element function
++++++++++++++++++++

If the element of each lattice point should depend on its position, a function can be passed as ``element``. The function is called for every lattice point with four arguments ::

    def element(i: int, uv: Tuple[int, int], xy: Tuple[float, float], n: int):
        ...

where ``i`` is the index of the lattice point (in the order of the lattice points), ``uv`` the indices ``(i_u, i_v)`` of the lattice point, ``xy`` its coordinates and ``n`` the total number of lattice points. (For a :class:`~fibomat.arrangements.DimLattice`, ``xy`` is a :class:`~fibomat.linalg.DimVector`.) The function returns the element of the lattice point. The element is moved with its pivot to the lattice point; it does not matter where the returned shape is located. If the function returns ``None``, the lattice point stays empty (vacant).

Rectangular lattices
++++++++++++++++++++

To generate a rectangular lattice (a lattice with orthogonal lattice vectors), the distances of the lattice points (``pitch_x`` and ``pitch_y``) and the number of points in each direction (:meth:`~fibomat.arrangements.Lattice.from_counts`) or the size of a rectangle (:meth:`~fibomat.arrangements.Lattice.from_rect`) must be given, as well as an element. ::

    from fibomat.arrangements import Lattice
    from fibomat.shapes import Spot

    # 3 x 4 points, the position of the spot does not matter
    spot_lattice = Lattice.from_counts(n_x=3, n_y=4, pitch_x=.75, pitch_y=.5, element=Spot((0, 0)))

The lattice is centered at ``center`` (by default (0, 0)). With :meth:`~fibomat.arrangements.Lattice.from_rect`, the lattice is centered in the rectangle and all points which fit in the rectangle are used (points on the edges included): a rectangle with the width 10 and a pitch of 2 contains 6 points, a pitch of 3 gives 4 points. ::

    lattice = Lattice.from_rect(width=10, height=6, pitch_x=2, pitch_y=3, element=Spot((0, 0)))  # 6 x 3 points

Suppose now that the element of each lattice point should depend on the lattice indices. To accomplish this, we pass a function as element. In the following example, an ellipse is scaled based on the position in the lattice ::

    from fibomat.shapes import Ellipse

    def ellipse_generator(i, uv, xy, n):
        ellipse_base_radius = .1
        u, v = uv
        return Ellipse(a=ellipse_base_radius + 0.05 * u, b=ellipse_base_radius + 0.05 * v)

    ellipse_lattice = Lattice.from_counts(n_x=4, n_y=4, pitch_x=.5, pitch_y=.5, element=ellipse_generator)

If the function returns ``None``, the lattice point is kept vacant. This can be used to generate a checkerboard pattern, for example. ::

    def checkerboard_generator(i, uv, xy, n):
        u, v = uv
        if (u + v) % 2 == 0:
            return Rect(width=.2, height=.2)
        return None

    checkerboard_lattice = Lattice.from_rect(
        width=1.6, height=1.6, pitch_x=.2, pitch_y=.2, element=checkerboard_generator
    )

Lattices of patterns and sites have units. They are created with the :class:`~fibomat.arrangements.DimLattice` class ::

    from fibomat.arrangements import DimLattice

    square_pattern_lattice = DimLattice.from_counts(
        n_x=3, n_y=3, pitch_x=2 * unit('µm'), pitch_y=2 * unit('µm'), element=pattern
    )
    site.add_pattern(square_pattern_lattice)

    # a lattice of sites. All sites are added to the layout
    site_lattice = DimLattice.from_counts(
        n_x=4, n_y=4, pitch_x=4 * unit('µm'), pitch_y=4 * unit('µm'),
        element=Site(dim_center=Vector(0, 0) * unit('µm'), dim_fov=Vector(3, 3) * unit('µm')),
    )
    layout.add_site(site_lattice)

Note that the elements of a lattice are moved in their own units. If a lattice of patterns is created by a function and one pattern has a shape which is defined in ``µm`` and another one in ``nm``, the result is still a regular lattice, because the positions are converted to the unit of each element.

The attributes of a lattice are ``u`` and ``v`` (the lattice vectors), ``points_uv`` (the indices of the lattice point of each element), ``n_points`` and ``elements_by_uv`` (an array of the elements with the shape ``(n_v, n_u)``, which contains ``None`` for vacant lattice points). They stay valid if the lattice is transformed.

Lattices with arbitrary lattice vectors
+++++++++++++++++++++++++++++++++++++++

To get finer control of the lattice, :meth:`~fibomat.arrangements.Lattice.from_boundary` can be used.
This method expects a boundary shape, two lattice vectors and an element (or element function). The lattice points are all points of the lattice which are inside of the boundary; points exactly on the boundary are not included. The boundary can be any closed shape, also a shape with holes (:class:`~fibomat.composite_shapes.HollowArcSpline`). The position of the lattice is defined by ``origin``, the position of one lattice point (by default, the center of the boundary).

To demonstrate the capabilities, first, a kagome spot lattice is generated within a circle. This type of lattice can be generated with a unit cell containing three spots arranged in an equilateral triangle and two lattice vectors of equal length which are rotated by 60° with respect to each other.

::

    spots = [(-.25 / 2, 0), (.25 / 2, 0), (0, .25 * np.sqrt(3) / 2)]
    unit_cell = Group([Spot(position) for position in spots])
    # the spots are given relative to the lattice point
    unit_cell.pivot = lambda _: Vector(0, 0)

    kagome_lattice = Lattice.from_boundary(
        boundary=Circle(r=2.5), u=(.5, 0), v=Vector(.5, 0).rotated(np.pi / 3), element=unit_cell
    )

As shown in the plot below (left site), the lattice is generated, but some spots of the unit cells are placed outside of the boundary if the unit cell is larger than the free space at the boundary. This can be prevented with an element function which only creates the spots of the unit cell that are inside of the boundary (right site in the plot). If no spot is inside, the function returns ``None``. Alternatively, the argument ``clip_elements=True`` removes all elements which are not completely inside of the boundary. ::

    boundary = Rect(5, 5)

    def unit_cell_inside_boundary(i, uv, xy, n):
        spots_inside = [
            Spot(position) for position in spots
            if abs(xy[0] + position[0]) < 5 / 2 and abs(xy[1] + position[1]) < 5 / 2
        ]
        if not spots_inside:
            return None

        group = Group(spots_inside)
        group.pivot = lambda _: Vector(0, 0)
        return group

    kagome_lattice_fixed = Lattice.from_boundary(
        boundary=boundary, u=(.5, 0), v=Vector(.5, 0).rotated(np.pi / 3), element=unit_cell_inside_boundary
    )

Due to numerical inaccuracies, it is advisable to use boundary edges which are not lattice planes.

Building lattices point by point
++++++++++++++++++++++++++++++++

Sometimes the element of every lattice point should be set individually. The lattice builders :class:`~fibomat.arrangements.LatticeBuilder` and :class:`~fibomat.arrangements.DimLatticeBuilder` are made for this: ::

    from fibomat.arrangements import LatticeBuilder

    builder = LatticeBuilder.rectangular(nu=5, nv=5, pitch_x=1, pitch_y=1)

    builder[0, 0] = Spot((0, 0))
    builder[1, 0] = Circle(r=.25)
    # ...

    lattice = builder.to_lattice()

The added shapes are moved so that their pivot is at the lattice point (hence, it does not matter where they are located initially). Lattice points can contain groups or even other lattices. If patterns or sites are added to a lattice, they are moved in their respective units.

Transformations of lattices
+++++++++++++++++++++++++++

Lattices are groups, so they can be transformed like groups: all elements are transformed together (and the lattice vectors are transformed, too). For example, a lattice can be rotated about its center ::

    rotated_lattice = lattice.rotated(np.pi / 6, origin='center')
