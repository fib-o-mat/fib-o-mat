Introduction
============

In the following, three different use cases are presented where the fib-o-mat package is successfully used to generate
FIB patterns.

To find out more about the scientific background, see the associated publication REF (it is open access and not behind
any paywall |:nerd:|).

.. note:: The scripts of the use cases were written for an older version of fib-o-mat and have not been ported to the current API yet. Use them as an illustration of the approach and see the :doc:`../user_guide/user_guide` for the current API.
